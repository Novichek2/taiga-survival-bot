# 🏕️ TAIGA Survival Bot

Telegram-бот-тренажёр для подготовки к автономной жизни в сибирской тайге.

## Цель
Не просто читать теорию, а проходить цикл: **изучил → ответил → выполнил → ошибся → повторил → прошёл сценарий**.

## MVP
- 🔥 Огонь
- 💧 Вода
- 🧭 Навигация
- 🏕️ Лагерь
- 🩹 Первая помощь
- ❄️ Зимняя автономность
- профиль и прогресс
- тесты и практические задания
- сценарии ЧС
- адаптивное повторение

## Безопасность
Бот не заменяет инструктора, врача или спасательную службу. Критические материалы должны проходить ручную проверку и иметь источники.

## Статус
MVP в разработке.
