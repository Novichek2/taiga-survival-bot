# 🏕️ TAIGA Survival Bot

Telegram-бот-тренажёр для подготовки к автономной жизни в сибирской тайге.

## Что уже работает

- регистрация Telegram-пользователя;
- PostgreSQL-хранилище;
- профиль навыков 0–100%;
- 6 учебных модулей: огонь, вода, навигация, лагерь, первая помощь, зима;
- интерактивные тесты через inline-кнопки;
- объяснение ошибки после ответа;
- уровни подготовки от «Городского» до «Руководителя»;
- аварийные сценарии с проверенными заранее вариантами;
- журнал попыток в БД;
- автоматические тесты GitHub Actions;
- Docker Compose с healthcheck PostgreSQL.

## Запуск

1. Создать `.env` на основе `.env.example`.
2. Получить токен бота через BotFather.
3. Запустить:

```bash
docker compose up --build
```

## Переменные

`BOT_TOKEN` — обязательный токен Telegram-бота.
`DATABASE_URL` — строка подключения PostgreSQL.
`ADMIN_IDS` — Telegram ID администраторов через запятую.
`LOG_LEVEL` — уровень логирования.

## Принцип обучения

**Изучил → ответил → получил оценку → понял ошибку → повторил → прошёл сценарий.**

## Безопасность

Бот не заменяет инструктора, врача или спасательную службу. Критические материалы должны проходить ручную проверку и содержать источники. Для медицинских и аварийных сценариев приоритетом являются безопасность, связь с экстренными службами и эвакуация.
